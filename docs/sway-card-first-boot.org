  - Only on the new card, explained:
    - cold first boot: the regulator core sets BOOST, vcc2v8_dvp,
      vccio_acodec and vdda_0v9 (0.9 -> 1.2 V, patch 0030) - card 1's
      snapshot came after a warm reboot, where RK817 keeps them;
    - first boot: machine-id generated, ldconfig 4.2 s, console-setup
      4.9 s (keymap es,us compiled) - should not repeat;
    - the Wi-Fi line ~done=1 ... acknowledged=1~ four times: it comes a
      while after boot (card 1's "after" was taken earlier), so it is
      timing, not a difference;
    - iio-sensor-proxy (new package) logs that the SC7A20 has no
      trigger/buffer - expected for a polled sensor; whether its
      polling works is checked with monitor-sensor.
    - ~Could not set hostname: Access denied~: systemd-networkd asks
      hostnamed to take a name from the router; without polkitd
      (pulled in on card 1 by a Recommends) it is denied. Fix:
      ~UseHostname=no~ for wlan0.
  - Only on card 1, explained: Bluetooth warnings of its paired device.
