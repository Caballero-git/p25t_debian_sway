#+TITLE: P25T kernel patches - common series (console and sway)
#+DATE: 2026-10-10

* What this is
  - 26 patches on mainline ~f2c53ea949c5048f96b3dbb5a5ee7131ce4ff2de~
    ("Merge tag 'net-7.3-rc5'", between 7.3-rc4 and rc5). Each patch
    carries a ~base-commit:~ line.
  - The same kernel serves both cards; only ~CONFIG_LOCALVERSION~ differs
    (~-p25t~ console, ~-p25t-sway~ Wayland).
  - Made from the 30 bring-up patches of ~p25t-linux~ (kernel/patches,
    0001-0030) by squashing the trial-and-error steps.

* Check against the old series
  The final tree equals the old series' tree except in the panel driver,
  where the bring-up log line ~p25t: init sequence sent ...~ is gone and
  two comments are reworded (no "bring-up" wording). No DT byte changed.
  Checked twice (2026-10-10): once while building the series, once by
  applying these files with ~git am~ on a fresh branch.

* Notes
  - All patches have Jose as author, with Co-Authored-By trailers.
  - The built-in panel mode in 0001 is still the stock 18/18/18 timing;
    the DT panel-timing node (0021) overrides it with 21/18/15. The DT
    node is what the tablet uses.
  - Patches keep the panel frame for touch (0015), the panel rotation 90
    (0020) and the landscape accelerometer frame (0022): a compositor
    relies on all three.
