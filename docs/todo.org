* Boot and stage 1
** TODO Volume-key rescue does not work
Stage 1 should stay in the stage-1 system when a volume key is held at
power-on (=docs/boot.org= of the bring-up, "Rescue and rollback").
- Found 2026-10-20 in the stage-1 logs: every boot of both cards logs
  "volume key ADC: unreadable". =initramfs/init= reads
  =/sys/bus/iio/devices/iio:device0=, but since the accelerometer was
  enabled (2026-09-26) device 0 is the SC7A20 and the keys' ADC is
  =iio:device1= (=fe720000.saradc=, idle value 1023).
- So the rescue path has never worked since then.
- Fix: find the IIO device whose name ends in =saradc= instead of using
  a fixed number. Then rebuild (=tools/build_initramfs.sh=).
- Test on the test card: a normal boot reaches Debian; a boot with a
  volume key held stays in stage 1 (the log shows a value below 900).
